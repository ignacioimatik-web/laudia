# Común de Santos

Textos comunes para categorías de santos que comparten el mismo tipo
de celebración (apóstoles, mártires, vírgenes, pastores, etc.).

## Esquema propuesto

```
common/
├── apostles.json        Común de apóstoles
├── martyrs.json         Común de mártires
├── virgins.json         Común de vírgenes
├── pastors.json         Común de pastores
├── doctors.json         Común de doctores de la Iglesia
├── holy-men-women.json  Común de santos y santas
├── dedication.json      Común de dedicación de iglesias
└── blessed-virgin.json  Común de Santa María Virgen
```
