# Salterio (4 semanas)

Estructura de datos para los salmos y antífonas del Salterio de la Liturgia de las Horas,
organizado en 4 semanas.

## Esquema

```
psalter/
├── week-1.json    Salmo 1– semana 1
├── week-2.json    Salmo 1– semana 2
├── week-3.json    Salmo 1– semana 3
└── week-4.json    Salmo 1– semana 4
```

Cada archivo contiene la distribución completa de salmos, antífonas y cánticos
del Antiguo Testamento para Laudes de cada día de esa semana del salterio,
conforme a la distribución oficial.
