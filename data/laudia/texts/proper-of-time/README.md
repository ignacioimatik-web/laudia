# Propio del Tiempo

Textos propios (himnos, antífonas, lecturas, preces, oraciones) para los
tiempos litúrgicos y solemnidades móviles.

## Esquema propuesto

```
proper-of-time/
├── advent/           Adviento (días 1–)
├── christmas/        Navidad
├── lent/             Cuaresma
├── triduum/          Triduo Pascual
├── easter/           Pascua
├── ordinary/         Tiempo Ordinario (semanas 1–34)
└── solemnities/      Solemnidades móviles (Ascensión, Pentecostés, etc.)
```

Cada archivo organiza los textos por día litúrgico,
usando la fecha ISO como clave (ej. `2027-03-28` para Domingo de Pascua).
